# Azelf

Responsive landing page and SVG brand assets, built from the supplied reference.

## Develop

```sh
npm install
npm run dev -- --port 4173
```

## Build

```sh
npm run build
npm run test:sites
```

The client build is in `dist/client`. The preserved Sites runtime is in `dist/server`.

## Brand assets

- `public/assets/azelf-mark.svg`: standalone vector logo with an accessible title and description.
- `public/assets/azelf-lockup.svg`: logo and wordmark. The wordmark uses system Helvetica/Arial; outline the text in a vector editor when exact typography is required across machines.

## Behavior and scope

Process steps reveal explanatory details and update the illustrative code state. The demo plays a deterministic, synthetic maintenance timeline. Dialogs support keyboard focus, Escape, backdrop dismissal, email validation, and completion states.

Early-access and repository forms are explicitly previews. They do not transmit or persist personal data, create registrations, connect repositories, or execute repairs. Wire a real signup service and repository authorization flow before public launch.

The page uses local assets and system fonts. No analytics, remote font service, or credentials are required.
